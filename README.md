# ÉCLAT Beauty Atelier

Учебный статический сайт — клиентская часть системы онлайн-записи в салон красоты
(курсовой проект, МДК 05.01, ПМ.05).

## Запуск
Откройте `index.html` в браузере или разместите папку на любом статическом хостинге
(GitHub Pages, Netlify и т. п.). Сервер и база данных не нужны.

## Возможности
- каталог услуг: фильтр по категориям, поиск, сортировка по цене;
- карточки мастеров;
- пошаговая запись: услуга и мастер → дата и время → контакты;
- проверка полей и блокировка занятого слота;
- «Мои записи»: просмотр и отмена (статус `cancelled`);
- хранение заявок в `localStorage` (ключ `eclat-bookings`);
- адаптивная вёрстка, доступность (aria, фокус, пропуск к содержимому).

## Структура
| Файл | Назначение |
|---|---|
| `index.html` | разметка страницы и диалоговых окон |
| `assets/style.css` | стили |
| `assets/catalog.js` | каталог (услуги, мастера) — **используется сайтом** |
| `assets/app.js` | клиентская логика |
| `data/catalog.json` | та же структура данных в формате JSON (для документации и будущего API) |

Данные каталога лежат в `catalog.js`, а не загружаются через `fetch`, чтобы сайт работал
при открытии файла двойным щелчком (браузеры блокируют `fetch` для `file://`).
При изменении каталога обновляйте оба файла.

## Публикация на GitHub Pages
1. Создайте на github.com новый публичный репозиторий, например `eclat-beauty-atelier`.
2. Загрузите в него содержимое этой папки (кнопка **Add file → Upload files**, перетащите всё, включая папки `assets` и `data`).
3. **Settings → Pages → Build and deployment**: Source — *Deploy from a branch*, Branch — `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://<ваш-логин>.github.io/eclat-beauty-atelier/`.

## Ограничения учебной версии
Данные не отправляются на сервер, нет авторизации, оплаты, синхронизации расписания
и серверной проверки. Занятость слота проверяется только по совпадению мастера, даты и времени.
